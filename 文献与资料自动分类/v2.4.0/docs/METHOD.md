# 方法学说明（METHOD）

## 设计原则

1. **确定性优先**：哈希、魔数、正则、规则表全部确定性执行，可复跑、可对账；
   模型只做规则识别、低置信抽验与契约填充。
2. **证据即交付**：每个字段带 source/confidence/evidence；每条决策带规则编号；
   缺失字段 null+not_found，不补造。
3. **不可逆操作禁止**：复制非剪切、归档非删除、冲突改名非覆盖；追加式审计日志
   + 全历史回滚脚本。
4. **管理指令优先**：组织方的别名表/版本说明/元数据表优先于启发式。

## 关键算法

- 版本分组：DOI 与（规范化标题+第一作者姓）与别名键的并查集合并；
  canonical 打分 = DOI+4/期刊+2/年份+1/标题+1/文本层+1。
- 检索：BM25（k1=1.5, b=0.75）+ 中英领域同义双向扩展（扩展词降权 0.7）+ 短语奖励 1.5×。
- 标签：受控词表同义合并 + 原文关键词直出，上限 6，防标签爆炸。

## 边界

不做文献检索发现、单篇精读、全文翻译、写作润色；OCR 不在范围内（扫描件如实标注）。
