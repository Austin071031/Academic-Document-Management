## (b) 共性短板定位（真跑验证）

**短板 #1（唯一且致命）：提交包契约违规 / 评测弃权**

| 假设 | 怎么验证（真跑） | 证据 | 归属 |
|-|-|-|-|
| description 超 1024B 上限导致 Skill 安装失败 | 实测三份 SKILL.md frontmatter 字节数，与平台结果对照 | 出分：690B（66.0）、1011B（64.67）；失败：1046B（3/3 evaluation_error）。同账号、同 CLI、同 harness、同周 | 全部维度（弃权型，归零） |
| bundle 含非 UTF-8/超限文件 | `zipfile` 逐个 decode 实测提交包 | 57 文件全部 UTF-8，NONE 非文本 → 排除 | — |
| 瞬时 worker 故障 | 同账号时间序列对照 | 88925 error→88926 scored（同分钟）；88927 scored→88980 error（同内容方向）；03:21–03:27 内 scored 与 error 交错 → **故障有瞬时分量** | 同上（重提可自愈） |

验证方法说明：以上均来自实采数据（platform_verified + 本地实跑），非经验猜测。
**结论：共性短板 = "评测弃权"，根因候选 #1 = frontmatter 字节越限，候选 #2 = 瞬时故障。**
v2.0.0 消除候选 #1（零风险、可机检），候选 #2 由重提吸收。
